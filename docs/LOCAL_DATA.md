# 收藏数据存储说明

## 概述

当前版本（v3.4.2+）的收藏功能已完全本地化，不再依赖网易云登录。
所有收藏数据均存储在用户本地，确保数据自主可控。

未来将通过独立服务器实现多设备数据同步，彻底替代网易云登录同步方案。

> 服务器构想详见 [SERVER_IDEA.md](./SERVER_IDEA.md)

---

## 存储位置

所有收藏数据通过 `localforage` 存储在 Electron 的 IndexedDB 中，
数据位于应用的用户数据目录下。

### 正常安装版

```
C:\Users\你的用户名\AppData\Roaming\KfunMusic\IndexedDB\
```

在文件资源管理器中输入 `%APPDATA%\KfunMusic` 可直接打开。

### 便携版

如果使用便携版（程序同目录有 `portable` 标识），数据存储在：

```
程序所在目录\UserData\IndexedDB\
```

### 存储键名

| 数据类型     | 存储键名            | 说明                             |
| ------------ | ------------------- | -------------------------------- |
| 我喜欢的音乐 | `local-liked-songs` | 收藏的歌曲列表（SongType[]）     |
| 我的收藏     | `local-liked-data`  | 歌单、专辑、歌手、视频、播客收藏 |
| 本地歌单     | `local-playlists`   | 用户创建的本地歌单（含歌曲详情） |
| 本地音乐库   | `local-songs`       | 本地扫描的音乐文件               |

> 注：IndexedDB 的实际文件由 Chromium 管理，通常以 `.leveldb` 目录形式存在，
> 不建议直接手动编辑文件，备份请备份整个 `IndexedDB` 目录。

## 数据结构

### 1. 我喜欢的音乐（local-liked-songs）

存储类型：`SongType[]`

```typescript
[
  {
    id: 123456, // 歌曲ID
    name: "歌曲名", // 歌曲名称
    artist: "歌手名", // 歌手
    album: "专辑名", // 专辑
    cover: "封面URL", // 封面
    type: "online", // 歌曲类型：online / local / douyin / streaming
    url: "播放地址", // 播放URL
    duration: 240000, // 时长（毫秒）
    // ... 其他歌曲字段
  },
];
```

**支持的歌曲类型**：

- `online` - 网易云在线歌曲
- `local` - 本地音乐文件
- `douyin` - 抖音收藏音乐
- `streaming` - 流媒体服务歌曲

---

### 2. 我的收藏（local-liked-data）

存储类型：`LocalLikeDataType`

```typescript
{
  playlists: PlaylistType[],    // 收藏的歌单
  albums: AlbumType[],          // 收藏的专辑
  artists: ArtistType[],        // 收藏的歌手
  videos: VideoType[],          // 收藏的视频/MV
  radios: DjType[],             // 订阅的播客电台
}
```

每项均存储完整对象数据，不依赖在线查询。

---

### 3. 本地歌单（local-playlists）

存储类型：`LocalPlaylistType[]`

```typescript
[
  {
    id: 1234567890123456,   // 歌单ID（16位数字）
    name: "我的歌单",        // 歌单名称
    description: "描述",     // 歌单描述
    cover: "base64封面",     // 歌单封面（base64格式）
    songs: SongType[],       // 歌曲列表（完整对象）
    createTime: 1234567890, // 创建时间戳
    updateTime: 1234567890, // 更新时间戳
  }
]
```

**说明**：

- 歌单封面自动取第一首歌曲的封面，转为 base64 存储
- 歌曲列表存储完整 `SongType` 对象，支持所有类型歌曲
- 去重逻辑使用 `id + type` 组合判断，避免不同来源 ID 冲突

---

### 4. 本地音乐库（local-songs）

存储类型：`SongType[]`

用户扫描本地目录添加的音乐文件，类型为 `local`。

## 操作方式

### 添加收藏

所有收藏操作均直接操作本地存储，无需网络请求：

- 点击红心按钮 → 添加到"我喜欢的音乐"
- 歌单/专辑/歌手/视频/播客详情页点击收藏 → 添加到对应收藏分类
- "添加到歌单"弹窗 → 添加到指定本地歌单

### 取消收藏

点击已收藏的按钮即可取消，数据立即从本地存储中移除。

### 数据持久化

所有收藏操作均自动保存到本地存储，应用重启后数据不丢失。

---

## 数据迁移

### v3.4.2 升级说明

从 v3.4.2 开始，本地歌单数据结构发生变化：

| 版本          | 存储格式                                |
| ------------- | --------------------------------------- |
| v3.4.1 及之前 | `songs: string[]`（仅存歌曲ID）         |
| v3.4.2 及之后 | `songs: SongType[]`（存储完整歌曲对象） |

**自动迁移**：应用启动时自动检测旧格式数据并转换，
尝试从本地音乐库中匹配歌曲信息，无需用户手动操作。

## 注意事项

1. **数据备份**：当前数据仅存储在本地，建议定期备份 `%APPDATA%\KfunMusic` 目录
2. **卸载清理**：卸载应用时可能会删除本地数据，请提前备份
3. **在线歌曲 URL**：在线歌曲的播放 URL 可能会过期，播放时会自动重新获取
4. **抖音收藏**：抖音收藏数据仍需通过 Cookie 从抖音获取，获取后缓存在本地
